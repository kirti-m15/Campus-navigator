# Campus Navigator

A Python-based Data Structures and Algorithms (DSA) mini project that models campus locations as a graph and helps users navigate between them.

## Features
- Represents campus locations using an adjacency list.
- Uses **Breadth-First Search (BFS)** to find the shortest route.
- Uses **Depth-First Search (DFS)** to explore reachable locations.
- Identifies disconnected locations and handles invalid inputs.

## Technologies & Concepts
- **Language:** Python
- **Data Structures:** Graph, Queue, Stack
- **Algorithms:** BFS and DFS

## How to Run
Run `campus_navigator.py` using Python 3.

## Purpose
To demonstrate the practical application of graph traversal algorithms in a campus navigation system.
